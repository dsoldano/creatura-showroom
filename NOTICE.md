# Scope of the licence

The MIT licence above covers the code and documentation in this repository:
viewer/, tools/, tests/, docs/ and the top-level files.

It does NOT cover the example project data under projects/ (today
projects/belvedere/). That folder contains:

  - Brigade Group marketing material (the published master plan, renders and
    the location map) and files derived from it (the upscaled plan, plan.jpg,
    the developer postcards, og.jpg), used here only to demonstrate the viewer
    on a real site plan rebuilt from public data. Copyright remains with
    Brigade Group; see projects/belvedere/source/PROVENANCE.md.
  - AI-generated images and clips (labelled "indicative" in the viewer),
    which are illustrations of that project and are not offered for reuse.

To use this software for your own project, supply your own site plan and
media in a new projects/<slug>/ folder (docs/adding-a-project.md).
